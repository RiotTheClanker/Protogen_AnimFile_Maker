## Protogen Animation Tool V3

Downloads: **Windows** `Windows_protogen_tool.exe` · **macOS** `Mac_protogen_tool` · **Linux** `Linux_protogen_tool`

### Fixes
- **Both sides of the face are now shown and editable.** In the 14-panel (Mk3) layout, the Painter only showed the left side (panels 0–6). The right side (panels 7–13) could never be painted, so it always exported black. Both layouts now draw side 1 on top and side 2 underneath.
- **The exported `fallback_anim.h` no longer changes the firmware's layout.** It used to define `PROTOGEN_LAYOUT`, which could silently turn the firmware into a 14-panel build. It now declares `FALLBACK_LAYOUT`, and ProtoFace V6.1+ refuses to build if it doesn't match.
- **Sound-triggered frames advance in the Simulator.** They move on when the volume rises past 128, after at least the frame's duration, matching the firmware. Before, they stalled forever.

### New
- **Mirror to other side** (on by default) paints the matching pixel on both sides.
- **Flip left↔right when mirroring** makes side 2 a mirror image: eyes swap, mouth panels reverse, and each panel flips horizontally.
- **Copy side 1 → side 2** copies a whole side, flipped or not.
- **Fill** buttons for each region on both sides.
- **Switching layouts keeps your artwork**, matched eyes → eyes, mouth → mouth, nose → nose.
- **Opening a file made for the other layout** offers to switch layouts.
- **The Export tab shows how many LEDs are lit on each side**, so an empty side is obvious before you export.

### Changes
- **The tool starts in the 11-panel (Mk2) layout**, to match the firmware default.
- **Faster** file loading and painting. The LED grid shrinks to fit smaller screens, and the mic shuts down cleanly.

Works with ProtoFace **V6.1**. The `.anim` file format is unchanged.
